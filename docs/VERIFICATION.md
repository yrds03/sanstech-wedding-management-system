# Catatan verifikasi ? 26 November 2026

## Implementasi yang diperiksa

Hosting Vercel yang sudah ada dipertahankan. Backend Supabase diganti dengan Google OpenID Connect dan snapshot PostgreSQL/PGlite terenkripsi di Google Drive. Spreadsheet/folder tujuan berasal dari tautan pemilik pada 26 November 2026. Migration lama dipindahkan utuh ke `database/migrations/`.

Lingkungan: Windows, Node.js 24.22.1, Next.js 16.4.6, React 19.3.1, PGlite 0.6.0, PostgreSQL 17.12, Vitest 5.1.1 dan Playwright 1.65.1/Chromium.

## Pemeriksaan yang sudah lulus

- `npm test`: **89 tes lulus**. SQL memakai migration yang sama dengan runtime; identitas dan sesi Google untuk pengujian dibuat secara terisolasi. Pemeriksaan mencakup header yang dapat dipasang ulang, kode login sekali pakai, PKCE/state/nonce, pemisahan deployment, tanda tangan Google, layanan yang belum tersedia, pembatasan aksi administrator, validasi impor, normalisasi timeout dan konfirmasi snapshot tanpa fallback ke cache ketika jaringan gagal.
- `npm run test:concurrency`: **5 skenario lulus** pada PostgreSQL 17.12 dengan koneksi independen: scan serentak tidak melampaui kapasitas, retry menghasilkan satu ledger, RSVP konsisten saat kapasitas berubah, kuota scanner tidak berlebih dan onboarding idempoten. Isi migration SQL tidak berubah ketika dipindahkan direktorinya.
- `npm run test:drive`: **4 skenario browser lulus pada masing-masing mode login**, total **8**: OIDC Web client langsung dan `WMS_TEST_GOOGLE_SCRIPT=1` melalui Apps Script. Alur meliputi pemulihan timeout melalui tombol Coba lagi tanpa logout, profil baru non-admin, workspace/acara/tamu, undangan lintas konteks browser, RSVP, check-in parsial, laporan CSV Free, logout serta penolakan cookie lama. Masing-masing mode menolak nonce dan tanda tangan identitas palsu. Layanan Google ditiru oleh preload lokal eksplisit; aplikasi produksi dan SQL berjalan tanpa mode demo. Preload tidak diimpor aplikasi dan menolak berjalan pada Vercel.
- `npm run test:e2e`: **5 skenario lulus**. Simulasi lokal memeriksa acara, template CSV/XLSX tanpa baris contoh, validasi unggah dan pembersihan file gagal, RSVP, pembacaan gambar QR PNG, check-in parsial, pesan operator TV, pairing layar, respons pembaruan yang sengaja ditunda sembilan detik, privasi nama tanpa izin, laporan XLSX, tampilan ponsel 390×844, CSRF, cookie palsu, tujuan undangan dan seluruh anchor panduan.
- Integrasi Drive memulihkan snapshot ke dua mesin terpisah dan menjalankan konflik compare-and-swap. Pengujian memeriksa isolasi tenant, aktor palsu, batas kapasitas, data publik yang disaring, pencabutan sesi, respons commit yang hilang dan pengulangan dengan kunci idempotensi yang sama, serta penolakan versi mundur berulang setelah cache dibuang.
- Pengujian gateway menjalankan `google-apps-script/Code.gs` di VM dengan layanan Google tiruan. Yang diperiksa meliputi kunci penulisan, versi, HMAC, timestamp, checksum, penolakan penulis eksternal, dan metadata spreadsheet tanpa isi snapshot. Enkripsi AES-256-GCM diuji terhadap perubahan byte serta kunci yang salah. Redirect gateway ke host lain ditolak.
- `npm run lint`, `npm run typecheck`, dan `npm run build`: selesai dengan kode keluar 0. Build mencakup pemeriksaan TypeScript. Artefak server ditelusuri: SQL dan aset WASM/data PGlite tercakup, sehingga tidak bergantung pada unduhan aset dari browser.
- `npm audit`: **0 kerentanan yang dilaporkan** pada dependensi terpasang. SDK Supabase dihapus; PGlite menjadi dependensi runtime dan `jose` memverifikasi ID token.

Total pemeriksaan otomatis: **107 tes lulus** (89 unit/integrasi, 5 transaksi bersamaan, 8 browser build produksi, 5 browser simulasi lokal). Build, lint dan pemeriksaan TypeScript juga selesai dengan kode keluar 0. Basis data simulasi lokal dikosongkan setelah pengujian.

## Masalah yang ditemukan dan diperbaiki selama pemeriksaan

- Katalog menampilkan harga modul Extra Quota, arsip tambahan dan souvenir yang belum aktif. Modul tersebut sekarang berstatus `unavailable` dan tidak ditawarkan pada katalog publik; layanan manual diberi ketentuan konfirmasi. Batas Free/Pro tidak diubah.
- Panduan lama masih menjelaskan kata sandi/email, tidak sesuai login Google. Panduan sekarang memuat tiga belas bagian, tabel tujuh kolom impor, hasil yang harus diperiksa, checklist uji coba dan bantuan. Ilustrasi tamu contoh pada beranda serta baris contoh template dihapus.
- Memilih file gagal setelah file valid dapat menyisakan isi impor lama. Formulir sekarang membersihkan isi sebelumnya, mengunci input sebelum siap serta submit saat membaca/error, dan membatalkan hasil pembacaan yang sudah diganti. Kapasitas kosong, izin TV keliru, kolom berlebih dan panjang isian ditolak. Impor Free terkunci di UI sesuai SQL.
- Pesan operator TV semula memuat kode enam angka sebagai token sesi `/display/...`. Pesan kini memakai URL portal `/tv?code=...`. Batas tunggu pembaruan layar disesuaikan dengan pembacaan/commit Drive, tetap satu permintaan pada satu waktu.
- Permintaan aksi admin tidak dikenal sebelumnya dapat masuk ke penyimpanan harga default. Aksi tersebut serta ID acara/paket yang tidak valid sekarang ditolak sebelum mutasi.
- Pembacaan berulang Drive kini mengirim konfirmasi metadata jika versi **dan** checksum masih sama. Pengukuran Google sesungguhnya: respons penuh 6.400.939 byte dan konfirmasi 169 byte, masing-masing sekitar 6,3 dan 2,9 detik pada satu percobaan. Setiap pembacaan tetap memeriksa Drive; kegagalan jaringan tidak menggunakan cache sebagai cadangan.
- Regresi lokal mengungkap pemuatan ulang otomatis source pada server pengembangan yang membatalkan navigasi setelah respons RSVP 303 yang benar. Berkas runtime dipisahkan dari pemantauan source dan kanal hot reload tidak dipakai oleh harness browser lokal. Build produksi tetap diuji terpisah dengan layanan Google terisolasi.
- Timeout upstream berupa `DOMException` mempunyai message read-only dan dapat mengganggu formatter error server. Transport sekarang mengubah timeout/abort menjadi error layanan terstruktur. Halaman pemulihan berbahasa Indonesia menggunakan API `retry()` Next.js 16 untuk mengambil ulang data, tanpa membocorkan detail exception.
- Konfigurasi pengujian lokal memakai penunjuk nonaktif nonkosong agar file environment produksi tidak mengisi variabel yang dianggap kosong oleh host. Sebelum setiap skenario simulasi, pemeriksaan layanan harus menyatakan database tidak dikonfigurasi. Audit produksi setelah pemeriksaan tetap menunjukkan snapshot versi 1 dengan nol pengguna, workspace, acara, grup, RSVP, check-in, undangan anggota dan sesi layar.

- Snapshot awal mesin database melampaui batas 4 MiB. Pengujian pada transport produksi menemukannya saat login; batas menjadi 8 MiB base64, di bawah batas `File.setContent` Google 10 MB. Pengujian database saja dengan penyimpanan tanpa batas tidak dipakai sebagai bukti transport siap.
- Pembuatan ulang mesin database pada setiap operasi menambah waktu dan alokasi memori. Mesin boleh dipakai ulang setelah versi/checksum Drive diperiksa kembali. Konflik atau respons commit yang hilang membuang cache; operasi tidak memakai salinan lama sebagai cadangan ketika Drive gagal.
- Intersepsi Playwright awal tidak menangkap tujuan redirect karena routing hanya berlaku pada permintaan pertama dalam rantai. Fixture diperbaiki untuk memeriksa respons POST sesungguhnya lalu membuka tujuan Google secara terpisah.
- Tes ekspor build produksi semula meminta format default Excel pada paket Free dan ditolak HTTP 403 sesuai aturan. Tes kini menggunakan tautan CSV yang benar dari halaman laporan; hak paket tidak dilonggarkan.

- Permintaan masuk dibatasi 4 MiB, di bawah batas platform Vercel 4,5 MB. Pratinjau impor menghitung ukuran formulir setelah pengodean Unicode dan normalisasi baris, lalu menolak pengiriman terlalu besar. Snapshot Drive 8 MiB dikirim antarlayanan dan tidak menjadi payload dari browser.

## Kondisi akun dan layanan

- Apps Script API diaktifkan pemilik dan autentikasi CLI Google/Vercel berhasil. Proyek bound spreadsheet yang diberikan dipakai, tanpa membuat proyek pengganti. URL gateway pemilik dipertahankan.
- Delapan tab header dan kamus kolom sudah dibuat **langsung di Google Sheets**. Pengulangan menghasilkan nol tab baru; baris header juga diverifikasi dari CSV Google sebenarnya, HTTP 200. Tab lain tetap ada. Templat kolom tidak dianggap sebagai salinan transaksi: data utama tetap snapshot Drive terenkripsi.
- Akses publik Sheet dan folder ditemukan sebagai writer, ditutup bertahap menjadi reader lalu **owner saja**. Metadata Drive terakhir memverifikasi Sheet, folder dan snapshot hanya mempunyai satu permission owner. Secret tidak dikirim ketika editor publik masih terbuka. Gateway kini menolak file dengan akses publik maupun editor/pembaca tambahan.
- Kode final gateway diterbitkan sebagai versi 11 pada deployment pemilik yang sama. Deployment login versi 5 pada proyek yang sama terverifikasi `USER_ACCESSING`/`ANYONE`, scope identitas saja; akses anonim diarahkan HTTP 302 ke login resmi Google. Jalur installer sementara sudah dihapus dari versi aktif. Cadangan sumber sebelumnya disimpan privat, tidak di Git.
- Pemilik memberi persetujuan eksplisit pemasangan secret melalui HTTPS setelah pemeriksaan otomatis memintanya. Secret baru dipasang di Script Properties; enam pengaturan koneksi disimpan terenkripsi pada target production Vercel. Tidak ada pengunduhan seluruh secret produksi. Nilai rahasia tidak dimasukkan ke chat, laporan atau Git.
- **Drive produksi benar-benar diuji:** pembacaan awal versi 0 berhasil sekitar 3,2 detik. Skema tiga migration disimpan melalui commit CAS menjadi versi 1, snapshot terenkripsi 6.400.764 byte base64. Snapshot dibaca kembali, didekripsi dan dipulihkan ke mesin PostgreSQL terpisah: 0 pengguna, 0 workspace, 0 acara. Tidak ada seed atau akun palsu. Tab status berhasil disinkronkan. HMAC salah, timestamp kedaluwarsa dan commit dengan versi lama ditolak oleh gateway Google sebenarnya.
- Domain produksi mengembalikan **HTTP 200** pada `/api/health`: `status: ok`, `database: connected`, `auth: google`. Halaman login HTTP 200; POST login 303 menuju deployment identitas dengan cookie Secure/HttpOnly, state/nonce/PKCE, lalu 302 ke login resmi Google. Kode login palsu ditolak, CSRF lintas origin mendapat 403, API workspace tanpa sesi mendapat 401. Pembacaan dan pemulihan snapshot diulang setelah akses publik ditutup, tetap berhasil.
- Login Google nyata lintas akun belum dinyatakan teruji oleh fixture lokal; login pertama pengguna tetap mengikuti persetujuan resmi Google. Pengujian browser di atas memakai layanan Google terisolasi. Kamera/TV fisik tidak terhubung ke sesi pengerjaan.
- GitHub Actions belum diaktifkan karena token Git tidak mempunyai scope `workflow`; template berada di `docs/workflows/ci.yml`. Pemeriksaan di atas dijalankan secara langsung. Integrasi GitHub?Vercel yang sudah ada dipakai untuk deployment.
- Pembayaran, WhatsApp blast dan aktivasi add-on otomatis tetap tidak dihubungkan ke penyedia eksternal. UI menjelaskan pemesanan/konfirmasi manual.

Kondisi produksi terakhir diverifikasi melalui domain dan status commit Vercel ketika pembaruan dikirim. Konfigurasi yang belum tersedia memberi HTTP 503 pada pemeriksaan layanan dan menolak akses data, tanpa akun simulasi produksi.
